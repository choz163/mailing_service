# Веб-приложение для рассылки сообщений

## Описание
Это веб-приложение на Django позволяет пользователям управлять рассылками сообщений для клиентов. Приложение включает функциональность для создания, просмотра, редактирования и удаления рассылок, а также отправки сообщений по требованию. Пользователи могут регистрироваться, аутентифицироваться и управлять своими рассылками и получателями.

Использование

Регистрация и аутентификация

Пользователи могут зарегистрироваться, подтвердив свой email. После регистрации они могут войти в систему, а также восстановить пароль, если это необходимо.


Управление рассылками

Пользователи могут:



Создавать новые рассылки.

Просматривать, редактировать и удалять свои рассылки.

Отправлять сообщения по требованию.


Управление клиентами

Пользователи могут:



Добавлять, просматривать, редактировать и удалять получателей рассылки (клиентов).


Статистика

Приложение собирает и отображает информацию о количестве успешных и неуспешных попыток рассылок пользователя и количестве отправленных сообщений.


Структура проекта


users/ — приложение для управления пользователями.

models.py — модели пользователей.

views.py — представления для управления пользователями.



mailings/ — приложение для управления рассылками.

models.py — модели для клиентов, сообщений, рассылок и попыток рассылки.

views.py — представления для управления рассылками и клиентами.

urls.py — маршруты для приложения.

forms.py — формы для регистрации пользователей.
